運営者情報

Pohoda は、杉本 啓輔が営む個人事業です。自社で企画・開発した iOS アプリと Web サービスを、アプリ内課金と Web の有料プランで提供しています。

基本情報

杉本 啓輔
事業形態
個人事業主（屋号：Pohoda）株式会社などの法人ではありません。
開業
2026年5月（東京都）
事業内容
自社で企画・開発した iOS アプリと Web サービスの提供アプリ内課金（サブスクリプション・買い切り）と Web の有料プランで提供iPhone アプリの受託開発（開発のご相談）
屋号の由来
「Pohoda（ポホダ）」は、チェコ語で「心地よい安らぎ」を表す言葉です。長く使える道具づくりを、屋号にしました。
