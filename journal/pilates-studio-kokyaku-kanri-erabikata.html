この記事の要点

ピラティススタジオの顧客管理は何で選ぶ？
回数券・月謝・予約の運営をまとめたいか、マシン・スプリング・左右や姿勢の変化を記録して引き継ぎたいかで選ぶと決めやすくなります。前者は予約システム、後者は記録のアプリの役割で、両方を併用するスタジオもあります。

  • 回数券・月謝・事前決済は、予約システムの役割。

  • 顧客の健康情報の保存先は、書かれていないサービスもあるので、導入前に確認する。

選ぶときの6つのポイント

回数券・月謝で通う会員を管理できるかピラティスは、回数券や月額で通う会員が多い業種です。予約のたびに回数券の残りが減る、月額会員だけが取れる枠を作れる、といった管理は予約システムの役割です。ここが手作業のままだと、予約とは別に残数の管理が続きます。
マシンの台数やグループの定員で、予約の枠を作れるかマシンピラティスは、マシンの台数が1回に入れる人数を決めます。グループレッスンなら定員です。予約システムが、台数や定員で枠を区切れるかを確かめます。この記事で比べた公式ページには、定員やマシンの台数で枠を作る機能の記載がほとんどありませんでした（Square 予約のプレミアムに「リソース管理」があります）。導入前に、体験や問い合わせで確かめてください。
マシン・スプリング・左右など、一人ひとりの記録を残せるかどのマシンで、どのスプリングで、何回、左右どちらをしたかが残ると、次回の内容を決めやすくなります。予約システムの顧客情報は、来店履歴や予約時の情報が中心です。毎回のセッションの中身を残すなら、記録のアプリを別に使う形もあります。
姿勢や痛み・配慮事項を、インストラクター間で引き継げるか担当が替わっても、姿勢の変化や痛む場所、配慮すべきことが伝わるかを見ます。姿勢の写真を同じ向きで並べられると、本人にも変化を見せやすくなります。
料金の形店舗ごとの月額、生徒1人ごと、使う人ごと、買い切り、決済の手数料と、数え方がサービスごとに違います。初期費用がかかるものもあります。会員やスタッフが増えたときに、合計でいくらになるかを見ます。
顧客の健康情報の保存先と扱い既往歴や痛みの記録は、慎重に扱う情報です。どこに保存されるか、誰が見られるかを、公式ページやプライバシーポリシーで確かめます。書かれていないときは、提供元へ問い合わせます。なお、会員が少ないうちは、紙のカルテや表計算でも十分に管理できます。

目的別の選び方

回数券・月謝・予約を、まとめて運営したいhacomono は、レッスンの予約、インストラクター指定、回数券の管理を一つで扱えると公式ページに書かれています。基本プランは1店舗35,000円/月（税抜）と初期費用があるので、会員の多いスタジオ向けです。小さく始めるなら、回数券の機能がある STORES 予約のフリープランから試す手もあります。
小さなスタジオで、まず費用をかけずに始めたいfreee予約、STORES 予約、Square 予約には無料のプランがあります。どれも予約が中心で、無料の範囲や決済の手数料が違います。セッションの記録は、KATACHI + も1人で使う分（顧客5人まで）が無料です。
マシン・スプリング・左右の記録と、姿勢の変化を残したいKATACHI + は、業種でピラティスを選ぶと記録の項目がマシンとスプリング・回数・左右に変わり、姿勢写真を同じ向きで並べられます。この記事で比べた予約システムの公式ページには、セッションの中身を記録する機能の記載はありませんでした。

KATACHI + について

この記事は KATACHI + の開発元 Pohoda が書いています。比較表の事実は、KATACHI + も他のサービスも、公開されているページから書きました。

KATACHI + は、パーソナルトレーナーと小規模ジム・スタジオのための、顧客カルテとセッション記録のアプリです。店舗を作るときに業種でピラティスを選ぶと、記録の項目がマシンとスプリング・回数・左右に変わります。姿勢写真を同じ向きで並べて変化を見せられ、カウンセリングシート、同意書への署名、予約台帳、PDF のレポートまでをひとつにまとめ、iPhone・iPad・Mac で使えます。顧客の記録は、自分の端末と iCloud にだけ保存され、開発元の Pohoda はサーバーを持たないので、記録を受け取ることも見ることもできません。オーナーがインストラクターの Apple アカウントを招待すると、同じ店舗のカルテと予約台帳を全員で見て記録できます。

1人で使う分（自分の店舗1つ・顧客5人まで）は無料です。顧客6人以上の記録やスタッフとの共有は、使う人それぞれが買い切り980円（一度だけ）です。回数券の管理、顧客が自分で予約する機能、決済はありません。予約台帳は、LINE や電話、外部の予約サービスで受けた予約を店舗側が記録するものです。日本国内の事業者向けで、医療・診断を目的としたアプリではありません。詳しくはKATACHI + の紹介ページをご覧ください。

よくある質問

ピラティススタジオの顧客管理は、紙やエクセルでもできますか？

できます。会員が少ないうちは、紙のカルテや表計算で足ります。回数券の残りを数え間違える、前回のマシンやスプリングを探すのに時間がかかる、担当が替わると配慮事項が伝わらない、といったことが増えたら、予約システムや記録のアプリに移すタイミングです。

予約システムと顧客の記録のアプリは、別々に必要ですか？

役割が違うので、目的しだいです。回数券・月謝・予約の受付・事前決済は予約システム（hacomono、freee予約、STORES 予約、Square 予約など）の役割です。毎回のマシン・スプリング・回数・左右や姿勢の変化を残すのは、記録のアプリ（KATACHI + など）の役割です。両方を併用するスタジオもあります。

マシンの台数に合わせて、予約の枠を作れますか？

この記事で比べたサービスの公式ページでは、マシンの台数や定員で枠を作る機能について、はっきりした記載をほとんど確認できませんでした。Square 予約のプレミアムには「リソース管理」があります。マシンピラティスで使うなら、導入前に提供元へ確かめてください。

顧客の健康情報は、どこに保存されますか？

サービスによって違います。KATACHI + は、顧客の記録を自分の端末と iCloud にだけ保存し、開発元の Pohoda はサーバーを持たないので、記録を受け取ることも見ることもできません。この記事で比べたほかのサービスは、公式ページに保存先が書かれていなかったので、導入前に提供元へ確認してください。

インストラクターが複数いると、料金はいくらになりますか？

サービスによって数え方が違います。KATACHI + は、スタッフを招待して共有するとき、使う人それぞれが買い切り980円（一度だけ）です。hacomono は1店舗あたりの月額、STORES 予約と Square 予約は店舗単位のプラン料金です。金額は変わることがあるので、各公式ページで確かめてください。
