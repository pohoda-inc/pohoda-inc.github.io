Thunderbird で ChatGPT を使う方法

Thunderbird の中で ChatGPT に返信を書かせたい。方法は、貼って頼む方法と、アドオンでつなぐ方法の2つです。

公開
2026年11月22日
書いた人
杉本 啓輔

この記事の要点

  • いちばん手軽なのは、メールをコピーして ChatGPT に貼る方法です。
  • アドオンでつなぐなら ThunderAI があり、ChatGPT は Web の画面経由なら API キーなしでも使える、と ThunderAI のページにあります。
  • メールの内容は外へ送られます。会社のメールは先に規則を確かめます。

目次

  1. 方法1　メールを貼って頼む
  2. 方法2　ThunderAI でつなぐ
  3. 気をつけること
  4. API キーを用意したくない人へ

方法1　メールを貼って頼む

  1. Thunderbird でメールを開き、本文をコピーします。
  2. ChatGPT の画面に貼り、頼みたいことを書きます（例：「この返信を、丁寧な口調で、日程は来週火曜の午後で調整したいという内容で書いて」）。
  3. 出てきた文を、Thunderbird の返信の画面に貼って、自分で直します。

宛名・日付・曜日・金額は、AI が間違えることがあります。送る前に、必ず自分で確かめてください。

方法2　ThunderAI でつなぐ

無料のオープンソースのアドオン ThunderAI は、ChatGPT に対応しています。ChatGPT は Web の画面経由なら API キーなしでも使える、と ThunderAI のページにあります。Thunderbird 140 以降で使えます。くわしくはThunderAI のページと、全体の記事で。

設定のしかたや、ChatGPT の契約・API の扱いは、ThunderAI のページと、ChatGPT を提供する会社の案内で確かめてください。ChatGPT の画面の契約と、API の契約は、別のものとして扱われることが多いので、どちらをつなぐのかを先に決めておくと迷いません。

気をつけること

外部の AI を使うと、メールの内容の一部が、その AI のサービスに送られます（自分の PC の中だけで動かす AI を除く）。会社のメールや、お客様の個人情報・機密を含むメールに使うときは、先に会社の規則を確かめ、許されないメールには使わないでください。

送った内容が、保存されるか、AI の学習に使われるかは、使うサービスの設定と規約で変わります。提供元のページで確かめてください。

API キーを用意したくない人へ

AI Mail Auto for Thunderbird は、API キーや ChatGPT の契約を自分で用意せずに、返信の下書きまで Thunderbird の中で作るアドオンです（中継サーバー経由で、使う AI は Claude です）。日本語の本文検索は無料、AI の機能は14日間のお試しのあと月 ¥1,000 です。ChatGPT に貼る方法で足りるなら、入れなくて大丈夫です。
