Thunderbird を便利にする設定とアドオン 2026

Thunderbird は、本体の設定だけでも、かなり使いやすくなります。検索・フィルター・タグ・テンプレート・ショートカット・表示を、無料の設定から順に、メニューの場所つきでまとめました。そのあとに、アドオンを、他の人のものも含めて正直に紹介します。

この記事の要点

  • Thunderbird は、標準の設定だけで、検索・振り分け・タグ・定型文・ショートカット・表示を整えられます。費用はかかりません。
  • 設定で足りないところだけ、アドオンを足します。AI の返信には、無料で自分の API キーを使う ThunderAI があり、API キーを用意しなくてよい月額のアドオンもあります（最後の段落）。
  • メニューの名前は Thunderbird 128 以降の日本語の画面を目安にしています。確認できなかった名前は、本文に書きました。

検索のコツ

探し物は、画面上部の検索ボックス（全体の検索）に語を入れて探すのが基本で、Windows・Linux は Ctrl＋K、Mac は ⌘＋K で開きます。件名・本文・差出人・宛先を、すべてのアカウントとフォルダーにわたって探します。

  • 複数の語を入れると、それぞれの語を含むメールが出ます。語を引用符（"）で囲むと、並び順のとおりのフレーズで探します。
  • Mozilla の説明では、全体の検索の索引は、3文字より短い語を索引に入れません。
  • ごみ箱と迷惑メールのフォルダーは、初期設定では検索の対象外です。フォルダーのプロパティで、全体の検索の結果に含めるかを選べます。
  • 条件を細かく決めたいときは、「メッセージを検索」を使います（Windows・Linux は Ctrl＋Shift＋F、Mac は ⌘＋Shift＋F）。選んだフォルダーを、索引に頼らず直接探します。

日本語は語と語の間に空白がないため、全体の検索で一部のメールしか出ないことがあります。直し方は、Thunderbird で検索がヒットしない・遅いときの直し方に手順を書きました。

メッセージフィルターで振り分ける

決まったメールを自動でフォルダーに移したいときは、メッセージフィルターを作ります。アカウントごとに、独自のフィルターの一覧を持ちます。

  1. アプリケーションメニューの「ツール」から「メッセージフィルター」を開き、「新規」を押します。
  2. 「フィルター名」を入れ、「フィルターを適用するタイミング」を選びます。初期設定は「手動で実行する」と「新着メール受信時」です。
  3. プロパティ（「件名」「差出人」など）・一致基準（「次を含む」など）・値を決め、動作（フォルダーへ移動、スターを付ける、など）を選んで「OK」を押します。
  4. すでに届いているメールにも使うときは、「メッセージフィルター」の画面で「今すぐ実行」を押します。移動先と条件を確かめてから押してください。届いているメールが、一度にまとめて動きます。

自動で動くフィルターは、受信トレイにだけ適用されます（アーカイブ時と送信後のフィルターは、その操作に含まれるメールだけ）。メッセージの本文で振り分けにくいときは、「迷惑メール分類後に実行」を選ぶと動くことがある、と Mozilla は説明しています。メッセージの上の差出人のアドレスを右クリックして「フィルターを作成」を選ぶと、その差出人を条件にしたフィルターの下書きができます。動かないときの確認は、自動振り分けができない・されないときに。

タグで目印を付ける

タグは、メールに色つきの目印を付ける機能で、「重要」「仕事」「プライベート」「To Do」「後で」の5つが初めから用意されています。自分で足すこともできます。

  • メールを選び、ツールバーの「タグ」から付けたいタグを選びます。外すときも同じ手順です。
  • メニューのタグに付いている数字のキー（1 から 9）を押すと、そのタグが付きます。0 を押すと、すべてのタグが外れます。
  • タグの追加・名前や色の変更・削除は、「タグ」のメニューの、タグを管理する項目から行います。
  • 付けたタグは、クイックフィルターバーの「タグ」で絞り込めます。

フィルターの動作に「タグを付ける」を選ぶと、振り分けと同時に目印も付けられます。

テンプレート（定型文）

よく書く文面は、Thunderbird 本体にテンプレートとして保存できます。アドオンは要りません。

  1. 新規メッセージに、よく使う文面を書きます。
  2. 「ファイル」の「名前を付けて保存」から「テンプレート」を選んで保存します。保存したものは、アカウントの「テンプレート」フォルダーに入ります。
  3. 使うときは、「テンプレート」フォルダーのテンプレートをダブルクリックすると、内容のコピーから新しいメッセージが開きます。

テンプレートの扱いは版によって少し違うので、文面を直すときは、保存し直したあとの「テンプレート」フォルダーの中身を確かめてください。文面を差し込む専用のアドオン（Quicktext など）もあります。

キーボードショートカット

よく使う操作は、キーを覚えると速くなります。次は Mozilla のキーボードショートカットの一覧にあるものの一部です（Windows・Linux は Ctrl、Mac は ⌘ を使います）。

表示と列を整える

メッセージリストは、列の出し入れ、並び替え、カード表示とテーブル表示の切り替えで、見やすくできます。

  • 列：列の見出しの右端のボタン（コラムピッカー）か、見出しの右クリックで、出す列と隠す列を選びます。見出しをドラッグすると並びを変えられ、境界をドラッグすると幅を変えられます。
  • 他のフォルダーにも同じ列を使うには、列の一覧の下にある「他のフォルダーにも適用...」を選びます。
  • カード表示とテーブル表示：Thunderbird 140 以降では、アプリケーションメニューの設定の「外観」（英語版は Appearance）で切り替えます。カード表示は2行か3行を選べます。
  • 新しいフォルダーの並び順（日付・件名・差出人）とスレッド表示の初期値も、同じ画面で決めます。

クイックフィルターバー

クイックフィルターバーは、いま開いているフォルダーのメッセージリストを、その場で絞り込む機能です。メッセージリストの上の「クイックフィルター」を押すか、Ctrl＋Shift＋K（Mac は ⌘＋Shift＋K）で出し、Esc で隠します。

  • ボタンは、「固定」（フォルダーを移っても絞り込みを保つ）・「未読」・「スター」・「連絡先」（アドレス帳にいる人）・「タグ」・「添付」です。
  • 検索欄に語を入れると、探す対象を、送信者・受信者・件名・本文に分けられます。
  • 「タグ」を押すと、複数のタグを「すべてに一致」か「いずれかに一致」で絞れます。

探せるのは、いま開いているフォルダーの中だけです。すべてのフォルダーを探すときは、全体の検索を使います。

検索フォルダー（保存した検索）

よくする検索は、検索フォルダーとして保存すると、一覧に出る専用のフォルダーとして、いつでもすぐ開けます。条件に合う新しいメールは、自動で加わります。

  1. フォルダーペインでアカウントを選び、「ファイル」の「新規作成」から「検索フォルダー...」を選びます。
  2. 名前と、検索する元のフォルダーを選びます。
  3. 条件（差出人・件名・タグ・日付・添付の有無など）を決めます。「すべてに一致」か「いずれかに一致」を選べます。

注意が二つあります。検索フォルダーのメールは、コピーではなく元のメールそのものなので、ここで消すと元のメールも消えます（フォルダー自体を消しても、元のメールは消えません）。また、本文の検索には時間がかかり、元のフォルダーを増やすほど遅くなります。

アドオンで足す

本体の設定で足りないところは、アドオンで足せます。アドオンは、メールに触れる権限を持つものがあるので、入れ方と確認の観点は、Thunderbird のおすすめアドオン 2026にまとめています。

  • 送信の予約：Send Later。
  • 定型文の差し込み：Quicktext。
  • メールの書き出し・バックアップ：ImportExportTools NG。
  • 連絡先の管理：CardBook。
  • AI の返信の下書き・分類：ThunderAI（オープンソース・アドオンは無料。自分の ChatGPT アカウントか API キーが要り、Thunderbird 140 以降）。API キーを用意しなくてよい月額のアドオンもあります（最後の段落）。

Thunderbird の公式の AI（Thunderbird Assist）は、開発チームの説明では、有料の Thunderbird Pro 側で提供する予定です（2026年11月時点・公開日は未定）。選び方は、Thunderbird で AI を使う方法 2026に、設定での自動化は、Thunderbird を自動化する方法 2026にまとめています。

日本語の検索と、返信の下書きがほしい人へ

ここまでの設定で足りないときの一つの選択肢が、私たちが作っている AI Mail Auto for Thunderbird です。Thunderbird 128 以降の、Windows・Mac・Linux の PC のアドオンで、日本語のメールを本文まで探せる検索は無料です。返信が必要なメールへの AI の下書き・分類・修正からの学習は、14日間のお試しのあと月 ¥1,000（税込）で、API キーは要りません。14日間のお試しはカードの登録が必要です。お試しの期間内に解約すれば請求は発生しません。AI が作るのは下書きまでで、自動では送らず、iPhone では動きません。入れただけでは何も変えないので、上の設定で足りる人は、入れなくて構いません。

よくある質問

Thunderbird を便利にするには？

まず本体の設定で整えます。検索（Ctrl＋K）、メッセージフィルター、タグ、テンプレート、キーボードショートカット、列の表示、クイックフィルターバー、検索フォルダーは、どれも無料です。足りないところだけアドオンで足します。

Thunderbird の便利なアドオンは？

送信の予約なら Send Later、定型文なら Quicktext、書き出しなら ImportExportTools NG、AI の返信なら ThunderAI（無料・自分の API キー）があります。API キーを用意しなくてよい月額のアドオンもあります（最後の段落）。
