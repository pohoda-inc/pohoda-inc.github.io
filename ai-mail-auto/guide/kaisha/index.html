会社でまとめて入れる手順

会社の管理者の方が、法人契約を申し込み、社員に入れてもらい、人数を管理するまでの手順です。1人あたり月 ¥1,000（税込）、2人分から、14日間のお試しがあります。

目次

  1. 申し込み
  2. 管理画面へのログイン

申し込み

  1. 法人契約の申し込みのページを開きます。
  2. 会社の情報、管理者のメールアドレス、人数（2人から）を入れます。
  3. 法人向けの規約（利用規約第3条の4）を読んで同意します。会社として、AI の処理を米国の Anthropic に再委託することの承諾も、ここで管理者が行います。使う人の初回の案内では、同意のチェックの代わりに、会社の管理者が AI の利用を決めていることが表示されます。
  4. 支払い方法を選びます。クレジットカード、または請求書払い（銀行振込・支払期限は請求書の発行日から14日）です。お試しは14日間で、お試しのあいだは請求しません。
  5. 当方は適格請求書発行事業者ではないため、お送りする請求書・領収書は適格請求書（インボイス）ではありません。仕入税額控除への影響は、会社の経理担当や税理士にご確認ください。
  6. 請求書払いでは、メールアドレスの確認のリンク（15分）が届きます。リンクを開いてボタンを押すと、申し込みが完了します。最初の請求書の支払いが確認できるまでは、席は10まで、AI は1人あたり月 ¥200 まで、招待は1日に席の数までです。

会社の規則や、メールの相手方への扱いに照らして、外部の AI にメールの内容の一部を送ってよいかは、申し込む前に、会社で確かめてください。会社の決まりで AI を使わないと決めれば、検索と送る前の確認だけを使えます。

管理画面へのログイン

  1. mail-ai.pohoda.jp/admin/login を開き、管理者のメールアドレスを入れます。
  2. 届いたメールのリンクを開きます。パスワードはありません。リンクは15分で切れ、1回だけ使えます。ログインは8時間です。

管理者は、1社で3人までです。管理画面は、概要・使う人・人を追加する・会社の決まり・人数と請求・管理者・操作の記録、の7つのページです。使う人の一覧では、人ごとの停止・再開・取り外し、手で渡すキーの発行ができます。

管理者に見えるのは、参加している人の名前・メールアドレス・最後に使った日・今月の AI の使用量（月の目安に対する％。金額は出ません）・PC の台数です。メールの中身と検索の内容は、管理者にも見えず、Pohoda のサーバーにもありません。学習したルールと設定は、同期を使う場合だけ、PC の中で暗号化した形で置かれ、Pohoda にも管理者にも読めません。

社員が自分で入れる（おすすめ）

情報システムの作業は要りません。管理者が会社のドメインを登録し、社員が自分で入れます。

  1. 管理画面で、参加できるドメイン（例 @example.co.jp）を登録します。登録できるのは、管理者のメールアドレスのドメインだけです。gmail.com などのフリーメールのドメインと、ほかの契約が登録しているドメインは、登録できません。
  2. 社員に、アドオンを入れてもらいます（入れ方は使い方の「入れ方」）。
  3. 入れると開く「使い始める」の画面で、社員が「会社の契約で使う」を選び、会社のメールアドレスを選びます。
  4. その Thunderbird に確認のメールが届きます。メールの4桁の数字が画面の数字と同じことを確かめて、「参加する」を押すと、席が割り当てられ、自動で使えるようになります。

1つのメールアドレスが1席で、1席で使える PC は、直近30日で3台までです。席のキーは PC ごとに分かれるため、いまの版では、同じ人の PC の間でも設定と POP の整理はそろいません（同期しません）。PC ごとに設定してください。

会社の決まりは、管理画面の「会社の決まり」で決めます。AI を使うか、自動の下書き、送る前の確認の細かさ、ご意見・インタビューのお願いを社員に表示するか（初めは表示しません）、などです。決めた項目は、使う人の設定画面で「会社の管理者が決めています」と出て、変えられません。AI の使いすぎを防ぐ月の目安は、Pohoda が決めます。目安を超えた人は、その月だけ AI が止まり、検索と送る前の確認は使えます。1人ごとの月の金額の上限は、設定できません。

情シスがまとめて配る（任意）

社員に操作をしてもらわず、全部の PC に入れておきたいときの方法です。使う人のすることがなくなります。必須ではありません。

管理画面から、会社用の policies.json をダウンロードします。中身は、アドオンを入れる指示と、会社の参加用の配布用の設定ファイル（トークン）です。形は次のとおりです（<トークン> の部分は、管理画面のものに置き換わります）。

{
  "policies": {
    "Extensions": {
      "Install": ["https://mail-ai.pohoda.jp/download/tb-ai-mail.xpi"]
    },
    "3rdparty": {
      "Extensions": {
        "tb-ai-mail@pohoda.jp": {
          "enrollToken": "<トークン>"
        }
      }
    }
  }
}

アドオンは、起動のときにこのトークンを読み、その PC の Thunderbird のメールアドレスと表示名を送って、参加を申し込みます。参加できるドメインに当てはまるか、管理者が招待したアドレスだけが保存されます。そのアドレスに確認のメールが届くので、使う人がすることは、そのメールのリンク（24時間・1回だけ）を1回押すことだけです。押すと、席が割り当てられ、アドオンが自動でキーを受け取ります。Extensions と 3rdparty は、Thunderbird の会社向けの設定（policy-templates）の項目です。

Windows

  • ファイルで置く：Thunderbird のインストール先（thunderbird.exe があるフォルダー）に、distribution フォルダーを作り、その中に policies.json を置きます。
  • グループポリシーで配る：Thunderbird の ADMX テンプレート（thunderbird.admx と mozilla.admx、それぞれの .adml）を取り込み、「Mozilla」の中の「Policies for Extensions」と「Extensions」の項目で設定します。「Policies for Extensions」の中の「Managed storage of extensions」（Software\Policies\Mozilla\Thunderbird\3rdparty\Extensions）に、値の名前として tb-ai-mail@pohoda.jp、値として {"enrollToken": "<トークン>"} を入れ、「Extensions」の中の「Extensions to install」に、アドオンの URL を入れます。テンプレートは Thunderbird のバージョンに合うものを使ってください。

Mac

  • ファイルで置く：Thunderbird.app/Contents/Resources/distribution フォルダーに、policies.json を置きます。
  • 構成プロファイルで配る：Thunderbird が用意している org.mozilla.thunderbird の形式で、3rdparty の中に Extensions、その中にアドオンの ID（tb-ai-mail@pohoda.jp）の dict、という形で、同じ内容を設定します。配る前に、1台で試してください。

Linux

  • Thunderbird のインストール先の distribution フォルダー（thunderbird/distribution）、または /etc/thunderbird/policies に、policies.json を置きます。

台数が多いときは、グループポリシーや構成プロファイルでの配布が向いています。配ったあとは、Thunderbird を一度終了して、起動し直してもらいます。

このトークンは、全部の PC の設定に入るので、社外に出さないでください。漏れたときは、管理画面で作り直せます（参加済みの人には影響しません）。

ほかの渡し方

  • 招待のメール：管理画面でメールアドレスを入れると、入れ方とキーの受け取り用のリンクが届きます。リンクは7日間で、1回だけ使えます。
  • 手で渡す：管理画面でキーを発行し（その場で1回だけ表示されます）、使う人が設定画面に貼ります。キーは PC 1台ごとに1つです。1人で3台まで使えます（直近30日に使った PC で数えます）。

参加の確かめ方

  • 管理画面の「使う人」の一覧に、参加した人の名前とメールアドレス、最後に使った日、PC の台数が出ます。
  • 使う人の設定画面では、会社の管理者が決めた項目に「会社の管理者が決めています」と出ます。
  • 確認のメールのリンクは24時間で切れます。まだ使っていない確認のメールは、同じアドレスに1日3通までです。
  • 一覧に出ないときは、その人のメールアドレスが登録したドメインに当てはまるか、席が空いているか、確認のメールの数字が合っているかを確かめます。policies.json で配っているときは、置き場所とファイル名も確かめます。Thunderbird を終了して起動し直すと、参加を申し込み直します。

人数の増減

  • 人数は、管理画面の人数の変更から、変えます（Stripe のポータルでは変えません）。使っている席より少なくはできません。増やすと、その日から日割りで請求します。減らすのは、次の請求からです。
  • 席より少ない人数にするときは、先に、管理画面で参加者を取り外します。取り外すと、その人のすべてのキーが止まり、名前とメールアドレスは、すぐに消えます。取り外した人は、管理者が招待し直すまで、自動では参加しません。
  • 退職した人などは、管理画面で止める（あとで再開できます）か、外す（席が空きます）を選べます。

やめるとき

  • 管理画面の請求のページから、解約します。支払い済みの期間の終わりまで使えます。日割りの返金はしません。
  • 止まったあとも、検索と送る前の確認は使えます。AI の機能だけが止まります。
  • 請求書払いで、支払期限を過ぎても入金がないときは、連絡します。支払期限を過ぎると、その日から AI の機能が止まります（猶予の期間はありません。カードで請求できなかったときも同じです）。検索と送る前の確認は使えます。入金の確認後、すぐに再開します。
  • 契約が終わってから90日で、会社の情報は削除されます（プライバシーポリシー）。それより前に消したいときは、メールでご請求ください。
